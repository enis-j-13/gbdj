# S-01 · Story: Historische Tagesdaten aus einer lokalen Datei einlesen

## Nutzen

Als Strategieentwickler möchte ich Kursdaten lokal prüfen und importieren, damit ich Analysen ohne Brokerzugriff starten kann.

## Quelle, Parent und Entscheidungsstatus

[Product Brief](../product-brief.md): FR-03; FR-10 (Vorschlag); D-02, D-03, D-04. Parent: [E-01](E-01.md). Q-05 erlaubt diese Planung, nicht die Umsetzung.

Status: **Vorschlag zur Zerlegung bestätigter Produktziele**; konkretisierende Vorgaben in diesem Entwurf sind unbestätigt. Umsetzungsfreigabe: **nicht erteilt**. Veröffentlichung: **nicht erlaubt**.

## Scope und Nicht-Ziele

Ein vereinbartes UTF-8-CSV-Format, eine Währung; keine Downloads und kein Datenbankdienst.

## Akzeptanzkriterien

- [ ] AC-1: Eine gültige Referenzdatei mit mindestens zwei Instrumenten wird vollständig gelesen; Anzahl, Datum, Währung und OHLCV-Werte entsprechen dem freigegebenen Schema.
- [ ] AC-2: Leere Datei, fehlende Pflichtspalte oder nicht interpretierbarer Wert erzeugen eine konkrete Diagnose mit Datei/Spalte/Zeile; kein teilweise erfolgreicher Import wird ausgegeben.
- [ ] AC-3: Importbericht enthält Quelle, Daten-Hash, Zeitraum und Kennzeichnung synthetisch oder historisch; fehlende Lizenzfreigabe blockiert externe Datenverwendung.
- [ ] AC-4: Import funktioniert offline; Eingabedateien bleiben unverändert.
